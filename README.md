# Личный Health OS на Vercel

Самостоятельная версия схемы health-os-workshop: загрузка анализов и заключений, история показателей с графиками, рекомендации врачей, напоминания и чат по медкарте.

Оригиналы и структурированные записи хранятся в private Vercel Blob. В репозиторий не попадают документы, токены и пароли. Каждая запись хранится отдельно; одновременная загрузка разных документов не перезаписывает карту. Повтор идентичного файла определяется по SHA-256. Пересчёт mg/dl выполняет код по справочнику воркшопа.

## Запуск

Node.js 24, `pnpm install --frozen-lockfile`, `pnpm test`. Развёртывание на Vercel из этой ветки. Секреты задаются в Environment Variables: OPENAI_API_KEY, HEALTH_PASSWORD, SESSION_SECRET, BLOB_READ_WRITE_TOKEN. OPENAI_MODEL по умолчанию gpt-4.1-mini.

## Что доступно

- Вход по паролю и подписанная HttpOnly-сессия на семь дней.
- PDF, PNG, JPEG, WebP до 3 МБ на файл, несколько файлов по очереди.
- Оригиналы скачиваются только после входа.
- Показатели и визиты выводятся из всех сохранённых записей, без учебного пациента.
- Экспорт JSON содержит разборы и свод. Оригиналы скачиваются отдельно из списка документов.
- Чат получает актуальную карту и последние три пары реплик текущего диалога. После перезагрузки переписка очищается.

## Ограничения первой версии

Интерфейс восстановлен из рабочей версии воркшопа: боковое меню, графики анализов, профиль и напоминания. Данные часов можно импортировать JSON в разделе «Сон и пульс»; используются последние 90 дней. Telegram-бот пока не перенесён. Скриншоты одного анализа загружаются отдельно. Напоминания на сайте извлекаются из рекомендаций; автоматической отправки нет. Большие файлы требуют отдельного прямого загрузчика в Blob. Разборы ИИ нужно сверять с оригиналами. Автоматический резервный архив вне Vercel пока не настроен — используйте экспорт и скачивание оригиналов.

Исходные промпт, схема разбора и справочник взяты из health-os-workshop. Сайт не ставит диагнозов и не назначает лечение.

## Ultrahuman

ULTRAHUMAN_API_TOKEN хранится только в Vercel. Синхронизация по кнопке или Vercel Cron раз в сутки около 10:00 UTC (CRON_SECRET). Последние 7 дней перечитываются, чтобы учесть поздний синк кольца. Оригинальные ответы API хранятся отдельно по датам в private Blob и накапливаются без удаления; интерфейс показывает последние 90 дней. Сон, HRV, температура и восстановление — только из кольца. Шаги кольца сохраняются как ringSteps и не считаются шагами Apple Watch; Apple Watch ещё не подключены. Аналитика считает средние по фактически доступным данным, без подстановки нулей.

## Активность Apple Watch

Отдельный раздел activity. Бесплатный ручной импорт стандартного export.zip / export.xml Apple Health. Архив читается локально через fflate, передаются только дневные сводки выбранного источника Watch и тренировки. Данные iPhone, Ultrahuman и других часов не суммируются, точные дубли отсеиваются. Дневные файлы activity/watch/YYYY-MM-DD.json обновляются без накопления повторов; хранятся все импортированные даты, интерфейс и экспорт свода показывают последние 90 доступных дней. Дни определяются по локальной дате начала записи из экспорта; частичные дни могут отличаться от итогов приложения Fitness. Прочие показатели здоровья, маршруты и сырые файлы на сервер не передаются. Автоматической передачи Apple Health пока нет.
